# n8n Workflow Automation on Render

Deployment configuration to run [n8n](https://n8n.io) (open-source workflow automation) as
a Docker web service on [Render](https://render.com), backed by PostgreSQL.

## Files

- `Dockerfile`: builds on the official `n8nio/n8n` image and sets the port and protocol.
- `render.yaml`: Render blueprint with the service definition, environment variables, a
  generated `N8N_ENCRYPTION_KEY` and the PostgreSQL connection settings.

## Deploy

1. Create a PostgreSQL database and fill the `DB_POSTGRESDB_*` values in `render.yaml`
   (or set them as secrets in the Render dashboard).
2. Set `N8N_HOST` and `WEBHOOK_URL` to your own domain.
3. Create a Render Blueprint from this repository.

Secrets are never committed: the encryption key is generated by Render and database
credentials are set in the dashboard.
